# hzpp-tracker

Node/Express web app to view status updates of HŽPP trains using the same API that the [`official app`](https://play.google.com/store/apps/details?id=com.hzppispromobile&hl=en) uses.\
Displays delay updates and train composition information using images sourced from [`vagonweb`](https://www.vagonweb.cz/). Some wagon matching data sourced from [`hzpp.prometko.si`](https://github.com/vekejsn/hzpp.prometko.si/tree/legacy) (legacy branch).
